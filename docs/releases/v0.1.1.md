Correctness and security update to the v0.1.0 pre-release. **Upgrade recommended.**

**Pre-release.** An engineering tool for demonstration and controlled trials.

### Changed
- A claim whose checks all pass is now reported as `passed` / **CHECKS PASSED** (was `proven`); `all_proven` in the JSON report is now `all_passed`. Matching a sealed file and the configured rules does not establish that a claim is true.

### Fixed
- `junit_clean` could pass a report containing a `<failure>` because totals came from summary attributes that default to zero. Totals now come from the `<testcase>` elements, and a report whose declared totals disagree is rejected.
- The XML entity filter could be bypassed by a UTF-16 document; expat now screens every document for doctype and entity declarations.
- A path below a regular file reads as "cannot read" on Windows as well as POSIX.

Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/ProofBoard/blob/v0.1.1/CHANGELOG.md) for details.
